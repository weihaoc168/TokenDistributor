        Caveats

          Weighted cost

          Every "weighted" figure on this page is computed with one formula, so the tiers compare on a single scale:

          weighted_cost = output + 0.1 × (input + cache_creation) + 0.01 × cache_read

          It is a comparison proxy built from transcript usage records. It is not a bill, and it does not model per-model pricing.
